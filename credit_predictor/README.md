# Credit Predictor (Inadimplência)

Projeto de IA simples com Python + Gradio para prever inadimplência com base em idade, renda e dívida.

## Como usar

1. Instale as dependências:
```
pip install -r requirements.txt
```

2. Treine o modelo:
```
python train_model.py
```

3. Rode a interface:
```
python app_ui.py
```

Use `share=True` para gerar link público com Gradio.
